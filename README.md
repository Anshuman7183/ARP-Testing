# Hotel Booking Automation Framework

Automation testing framework built using:

- Playwright
- Cucumber BDD
- TypeScript
- Page Object Model (POM)

## Features

- End-to-end booking workflow automation
- BDD feature files
- Step definitions
- Hooks support
- Screenshot on failure
- Reusable architecture

## Tech Stack

- Playwright
- Cucumber
- TypeScript
- Node.js

## Run Project

```bash
npm install
npm test
